$ reqbeam --help
reqbeam — Open source API testing tool

Usage: reqbeam [command] [flags]

Commands:
  auth: Authenticate with the server
  workspace: Manage workspaces
  project: Manage projects (deprecated, use workspace)
  env: Manage environment variables
  request: Manage API requests
  collection: Manage request collections
  run: Execute requests or collections
  test: Run automated tests
  logs: View execution logs
  help: Show this help message

Global Flags:
  -h, --help: Print help information
  -v, --version: Print version information

Documentation: https://github.com/reqbeam/reqbeam
installation
$ # Quick Start
# Clone the repository $ git clone https://github.com/reqbeam/reqbeam.git $ cd reqbeam
# Install dependencies $ npm install $ npm run setup:all
# Start the development server $ npm run dev
$ # Docker Setup
# Run with Docker Compose $ docker-compose up -d
usage-examples
$ # CLI Usage Examples
# Authenticate and set up $ rb auth login $ rb workspace create my-project $ rb env add development -i
# Create and run requests $ rb request create -n "Get Users" -m GET -u "{{API_URL}}/users" $ rb run request "Get Users"
# Manage collections $ rb collection create "User API" $ rb collection add "User API" "Get Users" $ rb run collection "User API" --parallel
