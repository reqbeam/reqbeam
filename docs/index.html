Reqbeam

A simple, open-source API testing tool for developers.

Features

Core Features

  • HTTP request builder with all methods (GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS)
  • Query parameters and headers management
  • Request body support for JSON, form-data, and x-www-form-urlencoded
  • Multiple authentication types (No Auth, API Key, Bearer Token, Basic Auth, OAuth 2.0)
  • Syntax-highlighted JSON responses
  • Request history tracking
  • Collections for organizing requests
  • Environment variables for different API endpoints
  • Workspaces for team collaboration
  • Tab management for multiple requests
  • Mock servers for testing
  • Import/Export collections

Authentication & Security

  • User registration and login with NextAuth.js
  • Google OAuth integration
  • Persistent user sessions
  • Protected API routes
  • JWT tokens for CLI authentication

CLI Features

  • Command-line interface for automation
  • Real-time synchronization with web UI
  • Run collections from terminal
  • Automated testing with scheduling
  • Comprehensive execution logs
  • Replay past executions

Installation

Quick Start

Get up and running quickly:

git clone https://github.com/reqbeam/reqbeam.git
cd reqbeam
npm install
npm run setup:all
npm run dev

Docker Setup

Run with Docker Compose:

git clone https://github.com/reqbeam/reqbeam.git
cd reqbeam
docker-compose up -d

Usage Examples

CLI Usage

# Authenticate
rb auth login

# Create workspace and environment
rb workspace create my-project
rb env add development -i

# Create and run requests
rb request create -n "Get Users" -m GET -u "{{API_URL}}/users"
rb run request "Get Users"

# Manage collections
rb collection create "User API"
rb collection add "User API" "Get Users"
rb run collection "User API" --parallel

Architecture

reqbeam/
├── reqbeam-db/          # Shared database package
│   ├── prisma/         # Prisma schema and migrations
│   └── src/            # Database services
├── reqbeam-cli/        # CLI tool
│   ├── src/            # CLI source code
│   └── bin/            # CLI executables
├── auth-server/        # Optional authentication server
│   └── src/            # Auth server code
├── src/                # Next.js web application
│   ├── app/            # Next.js app router
│   ├── components/     # React components
│   ├── lib/            # Utilities and services
│   └── store/          # State management
├── prisma/             # Database files (SQLite)
├── public/             # Static assets
└── docker-compose.yml  # Docker configuration
